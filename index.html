De’vyora Natural Stone & Architectural Atelier

The studio application

De’vyora is a natural stone and tile atelier. This is the private web application its showroom runs: a tile catalogue, a reference image library kept by theme and room, a mood board generator, and a wishlist a client fills in on a tablet in the showroom.

Sign in For De’vyora staff. There is no public sign-up.

What it does

De’vyora Library

Reference rooms kept by theme and room type. The studio uploads its own; a client picks one, and it becomes the reference the visualisation is generated from.

De’vyora Select

The mood board generator: a brief, the catalogue’s own tiles, and a generated room for the client to look at.

Client wishlists

A client browses the library on a showroom tablet and hearts what they like. The studio keeps the register and prepares the proposal from it.

Sample placement

Where every physical tile sample sits in the showroom, by cassette and panel, found by barcode.

Google Drive

The studio can connect its own Google account so that the pictures the application holds live in the studio’s Google Drive rather than on this server. The connection is made once, by the studio owner, from inside the application. Clients are never asked for a Google account.

The only scope requested is drive.file, Google’s narrowest Drive permission: it reaches the files this application creates and the folder the owner explicitly picks, and nothing else in that Drive. No Gmail, Contacts, Calendar or profile access is requested.

Data and privacy

What the application stores, what it does with a connected Google account, how long it keeps it and how to revoke it are set out in full in the Privacy Policy.
